## 三、**未找到任何明文**要求申请书匿名的证据链

逐字通读以下三份独立文本，**均查无**"匿名""盲审""活页""不得出现姓名/单位/导师"之类表述：

1. 《国家自然科学基金条例》（国务院令第796号）**全文** —— 全文**不含"匿名"二字**；存在的是**回避**（第二十条）与**保密**（第二十一条）。
2. **2026 年度《项目指南·申请规定》全文**（15 页）—— 无"匿名""盲审""活页"。文中出现的"姓名"仅一处，且是**反向要求**（须如实填写导师姓名）。
3. **2019 年度《项目指南》全文** —— 同样无"活页"二字。"活页"主要是**国家社科基金等其他基金体系**的匿名论证页制度。

另经核实的两条常见传闻：

- **"2026 年起首轮匿名盲审"** —— **未经官方确认**。该说法仅见于第三方转载，且转载方**自行注明**基金委官网与正式通告均未提及。
- **"连续两年未获资助暂停一年"** —— **已于 2024 年度取消**，2024／2025 年度均明示；**不可作为检查项**。

**制度层面的反证**：条例第二十条要求"评审专家与申请人属于同一法人单位的"应当回避，这**假定系统知道申请人单位**；若实行匿名评审，该回避条款无从执行。故"申请书须匿名"在制度设计上不成立。

**本插件的处置**：NF-002~NF-009、NF-013 全部为**原则性推论 / 技术性提示**，严重级封顶 `info` 或 `warn`，
措辞统一写作"**身份线索词**"，报告文案明确写"**现行国家文件未禁止正文出现姓名或单位名称**"，
并在页脚免责声明之外，由每条规则的 `note` 单独说明无明文依据。**绝不写"不得出现姓名"，绝不作阻断。**

## 四、不得进入规则库的项

| 拟检查项 | 状态 | 原因 | 降级表述 |
|---|---|---|---|
| 正文不得出现申请人姓名 | **无明文** | 三份权威文本均无；指南反而要求列出导师姓名与代表作署名 | 已实现为 info/warn 技术性提示，措辞"身份线索词"，非"不得出现" |
| 活页／匿名页不得出现依托单位名称 | **无明文** | 无法证实 NSFC 现行体系存在"活页"制度；该制度属其他基金体系 | 不实现；仅在 README 中说明沿革无法核实 |
| 导师姓名不得出现 | **与明文相反** | 年度指南明确要求**如实填写**导师姓名 | 已实现为**反向检查** NF-014（防漏填），并说明与 NF-004 不矛盾 |
| PDF 元数据不得含身份信息 | **无明文** | 无任何国家文件规定；基金委流程本身要求上传含署名的简历与代表作 PDF | 已实现为 **info** 技术性提示，note 明写"未禁止" |
| 连续两年未获资助暂停 1 年 | **已废止** | 2024、2025 年度均明示取消 | 不实现 |
| 不予受理的**具体原因清单**（签名缺失、依托单位未确认等） | **部分未核实** | 年度初审结果通告**只公布总数与复审程序，不含原因清单**；网传清单来自 C/D 级统计 | 依据改为条例第十三条 + 年度指南"不予受理情形说明"；细项交由 NF-011 的机构配置 |
| 《国家自然科学基金项目申请受理审查要点》全部条目 | **该文件未核实存在** | 国家层面未见公开发布此名称文件；存在同名近似件实为某高校内部培训材料 | 不引用该文件名 |
| 页数统一限 30 页 | **仅当年有效** | 不同年度、不同项目类型的填报说明分别给出页数或字数上限，表述与数值逐年变化 | 已实现为 **NF-010 空配置**，须按当年指南填写 |
| 限项总数 2 项 | **仅当年有效** | 年度间已见变化 | 不硬编码；由 NF-011 的机构配置承担 |
| 《科研诚信案件调查处理规则（试行）》（国科发监〔2019〕323号）作为形式审查依据 | 文号已核实，**关联度低** | 该文针对案件调查处理程序；NSFC 现行为国科金发诚〔2022〕53号 | 未纳入本规则库 |

## 五、仍需使用方自行复核的项

1. **年度文件一律须按当年指南复核**：NF-010、NF-011、NF-012、NF-014、NF-015 的依据分别是当年指南或本机构配置，规则库中的摘录只是**核查时点**的版本。
2. **`nhc.gov.cn` 对自动抓取返回 HTTP 412** 的经验同样适用于部分部委站点；本次 NSFC 官网部分页面亦不可达，2026 年度指南全文以依托单位转载件为准（C 级）。
3. **未取得 B 级直链**：本次未能从 `nsfc.gov.cn` 原页取得 2026 年度指南与年度通告全文，故相关条款标注为 C 级。
